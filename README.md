# Agentic-tool-Reasoning-for-Small-LLm-Models

## How to run eval.py:

### 1.First install vllm with "pip install vllm" or "uv pip install vllm --torch-backend=auto'

### 2.Second install qwen agent with "pip install -U "qwen-agent[rag]"'
### 3.Third run vllm_launch.py file 
### 4.Fourth run eval.py
